PL-2 M폴더 구조패키지기초 지식

pl2_arm_bringup

팔 모듈 조립 — launch 3종 + 모듈 계약 + 컨트롤러 설정

실물 대응 — 팔 스택 기동 전체심 공용

팔 모듈을 실제로 띄우는 조립 지점이다. 진입점이 셋이다: 실물(pl2_arm.launch.py), 시뮬레이션(pl2_sim.launch.py), 시뮬레이션+동작 계획(pl2_sim_moveit.launch.py). 셋 다 같은 컨트롤러·게이트 구조를 쓴다 — 심은 하드웨어 플러그인 한 줄만 다르다.

팔이 외부에 공개하는 것을 적은 모듈 계약(contract/openarm_v1·v2)과 컨트롤러 실행 설정(config/controllers/)이 여기 있다. resolver 는 이 계약을 읽어 로봇을 조립한다.

로봇 전체 기동에서는 로봇 진입점(robot.launch.py)이 compute 보드에서 이 launch 를 불러온다. 단독 기동도 된다 — 모델(v1/v2)은 rig 기록을 따라 자동 결정된다.

03

핵심

#
세 진입점실물 pl2_arm · 심 pl2_sim · 심+계획 pl2_sim_moveit — 전부 같은 컨트롤러·게이트 구조, 심은 하드웨어 plugin 한 줄만 다르다
모듈 계약contract/ 가 팔의 공개 인터페이스(그룹·토픽·QoS)를 데이터로 선언 — resolver 의 입력
컨트롤러 설정config/controllers/ 가 JTC · 게이트 체인 · 브로드캐스터의 실행 배선을 가진다
게인 로더pl2_control_gains 가 description 소유 control_gains.yaml 을 읽는 한 철자 — 심도 같은 파일을 본다
모델 자동 결정단독 기동 시 rig 기록(module_revision)을 따라 v1/v2 결정 — env 는 명시 오버라이드일 뿐
04

빠른 시작

#
# 실물 팔 스택 (모델은 rig 기록이 결정)
ros2 launch pl2_arm_bringup pl2_arm.launch.py

# 심 — MuJoCo 물리로 같은 컨트롤러 구조
ros2 launch pl2_arm_bringup pl2_sim.launch.py model:=v2

# 심 + move_group 풀스택 (앱이 sim 세션에 자동 선택)
ros2 launch pl2_arm_bringup pl2_sim_moveit.launch.py model:=v2
05

실전 코드

#

단독 기동에서도 "이 로봇이 무엇인가"의 답은 rig 기록 하나다 — launch 의 모델 기본값이 캘리브레이션·스튜디오와 같은 해석(rig 기록 → v1/v2)을 따른다. 조립 경로(robot.launch.py)는 파생된 description 을 명시로 넘긴다.

src/pl2_arm/pl2_arm_bringup/launch/pl2_arm.launch.py

# The model default follows the rig record (env override -> record -> v2),
# the same resolution the calibration and the studio monitor use — one
# answer to "which robot is this" for a standalone launch.
from pl2_arm_payload.solver import active_model

# The user-facing `model:=v1|v2` arg maps to the description arm_type.
# Variant is data (config/openarm_v<n>), not a per-robot launch file.
_MODEL_TO_ARM_TYPE = {"v1": "openarm_v1.0", "v2": "openarm_v2.0"}
06

설정 파일 실물

#

팔 모듈 계약의 머리다. 이 팔이 무엇이고(provider · model · 자유도) 어떤 그룹을 공개하는지가 데이터로 선언된다 — resolver 의 입력.

contract/openarm_v2.contract.yaml (발췌)

contract_version: 1
module: arm
provider: pl2_arm
model: openarm_v2
dof_per_arm: 7

groups:
  arm:
    joints: [joint1, joint2, joint3, joint4, joint5, joint6, joint7]
    unit: rad
    command:
      topic: forward_position_controller/commands
      type: std_msgs/msg/Float64MultiArray

컨트롤러 실행 설정 — 어떤 컨트롤러를 띄우고 게이트를 어디에 끼울지 적은 배선이다. 게이트 클래스 문자열이 여기서 지정된다.

config/controllers/openarm_bimanual_controllers.yaml (발췌)

controller_manager:
  ros__parameters:
    joint_state_broadcaster:
      type: joint_state_broadcaster/JointStateBroadcaster
    left_safety_gate:
      type: pl2_arm_safety_controller/SafetyGateController
    right_safety_gate:
      type: pl2_arm_safety_controller/SafetyGateController
    left_joint_trajectory_controller:
      type: joint_trajectory_controller/JointTrajectoryController
